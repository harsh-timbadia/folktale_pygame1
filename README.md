# 🎮 Math Arcade Adventure

A sleek, terminal-based text adventure game built in Python. Test your mental math skills to earn tokens, navigate through the interactive rooms, and gear up your inventory at the local prize shop!

Built as a submission for **Hack Club Folktale**.

## ✨ Features

* **Interactive Navigation:** Move seamlessly between the Main Hall, Arcade Room, Math Quiz, and Prize Shop using simple numerical inputs.
* **Procedural Math Challenges:** The game uses Python's `random` module to generate unique addition, subtraction, and multiplication problems (using numbers 1-15) every time you play.
* **Economy System:** Earn 10 points for every correct math answer. 
* **Inventory Management:** Spend your hard-earned points at the Prize Shop. The game tracks your items and prevents you from buying duplicate gear.

## 🛠️ Requirements

* **Python 3.x** installed on your system.
* No external dependencies or packages required! It uses the built-in `random` module.

## 🚀 How to Run

1. Clone or download the project folder to your local machine.
2. Open your terminal or command prompt (or use the integrated terminal in VS Code).
3. Navigate to the folder containing the game file.
4. Run the script using Python:
   ```bash
   python firstgame.py
